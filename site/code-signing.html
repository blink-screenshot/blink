Code signing policy

How Blink releases are signed

Blink's Windows releases are code-signed so Windows can show who published them and that the files were not changed after the build.

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: Blink has applied for code signing through the SignPath Foundation. Until the first signed release is out, the installer is not signed and Windows SmartScreen warns about it. This page will say which version is the first signed one.

What is signed

Only files built from Blink's own source code in the public repository blink-screenshot/blink:

  • Blink-Setup.exe, the installer
  • Blink.exe, the app inside the installer, and the same file published as Blink-portable.exe
  • Uninstall.exe, the uninstaller the installer writes

Each signed file carries the product name Blink and the version of that release in its file properties. Software from other projects is never signed under Blink's name.

How a release is built

  • Every release is built and tested by GitHub Actions from the public source code. Nothing is built or signed on a personal computer.
  • A new version is first published as a pre-release, which the in-app updater does not offer. The maintainer installs and tests it before promoting it to a regular release.
  • Every signing request is approved by hand by an approver (see below). Nothing is signed automatically.
  • The release page lists the SHA-256 checksum of every file, and the in-app updater checks that checksum before it installs an update.

Team roles

RoleWho
Committers and reviewers Members of the blink-screenshot organization. Changes from anyone else arrive as a pull request and are reviewed by a member before they are merged.
Approvers Owners of the blink-screenshot organization.

Everyone with one of these roles uses multi-factor authentication for GitHub and for SignPath.

Privacy

Blink collects no personal data, has no account, no analytics and no telemetry, and never uploads screenshots. It makes one kind of network request on its own: a daily check with the GitHub API for a newer version, which contains no personal data and can be turned off in Settings > Updates. Text recognition uses the OCR engine built into Windows and works offline.

The full details, including the GitHub privacy statement that applies to the update check and to downloads, are in Blink's privacy policy.

System changes

The installer installs Blink per user in %LOCALAPPDATA%\Programs\Blink, without admin rights, and by default starts Blink with Windows, which can be turned off in the settings. Blink can be removed with its uninstaller, from Settings > Apps in Windows.

Reporting a problem

If you think a signed file did not come from this project, or something about a release looks wrong, please report it as described in the security policy.
